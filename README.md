# Angels N Brat - Brewpub Website

## 📋 Project Overview
A modern, responsive website for Angels N Brat brewpub featuring an interactive menu, event management, and customer engagement tools.

## ✨ Key Features
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Interactive Menu** - Browse beers, food, and special items
- **Event Calendar** - View upcoming events and promotions
- **Modern UI/UX** - Clean, intuitive interface for customers
- **Fast Performance** - Optimized for quick loading times
- **Mobile-Friendly** - Fully optimized for smartphones and tablets

## 🚀 Getting Started

### Prerequisites
- Node.js v14+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/bhavingupta128-oss/angels-n-brat.git

# Navigate to project
cd angels-n-brat

# Install dependencies
npm install

# Start development server
npm run dev
```
